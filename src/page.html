U1 Converter

Bambu Studio → Snapmaker U1 converter

Turns Bambu Studio filament presets and .3mf projects into files Snapmaker Orca accepts for the U1. Your files are processed in this page only; nothing is uploaded.

FROM · Bambu StudioTO · Snapmaker U1 / Orca
  1. 1
    Export from Bambu Studio

    File → Export → Export Preset Bundle, then choose the filament presets. You can also drop the raw .json files from BambuStudio/user/<id>/filament/.

  2. 2
    Drop it here and check

    Check the U1 base and nozzle picked for each filament, edit any result value or add your own overrides, then download the .zip.

  3. 3
    Import in Snapmaker Orca

    File → Import → Import Configs and pick the zip. Your filaments appear under Custom in the filament list when the U1 is selected.

How Bambu and Snapmaker U1 filament presets differ

AreaBambu Studio (P1S)Snapmaker Orca (U1)What the converter does
InheritanceUser presets point to a Bambu parent (e.g. Bambu PLA Basic @BBL P1S 0.4 nozzle) and store only the differencesThat parent doesn't exist, so the import silently skips the preset. That's the "0 configs imported" you get with Bambu files.Finds your real changes by comparing with the Bambu parent, then links them to a U1 parent
Hotend variants2-slot arrays: Direct Drive Standard / High Flow1- or 2-slot arrays: standard / high_flowMaps slot to slot; Standard → standard, High Flow → high_flow
Importer checks—Needs a valid version, a filament_settings_id, and a parent that existsWrites all three
Material propertiesDensity, cost, vendor, temperature range, softening tempSame keysAlways copied: they belong to the spool, not the printer
Temps, fans, cooling, flowTuned for the P1S hotendSame keys, tuned for the U1. U1 defaults run lower max volumetric speeds (e.g. Generic PLA 12 vs 21 mm³/s) and hotter beds (PLA 65 °C vs 55 °C)Copies your changes and flags flow-ratio and speed values to re-test
Filament G-codeBambu commands (M142, M106 P3 chamber/aux fans)Klipper firmware, U1 toolchanger macrosNot copied; you get a warning if you had customized it
Toolchange / ramming / purgeAMS cutter retraction (…_when_cut), flush settingsToolchanger retraction, multitool ramming, wipe-tower purgeKept at U1 values
Pressure advanceNot a filament setting (calibrated on the printer)Per-filament pressure_advanceKept at U1 defaults; recalibrate on the U1
Bambu-only featuresScarf seams per filament, overhang speeds, AMS drying, hole/circle compensation, chamber temperatureNo filament-level equivalent (about 70 keys)Dropped and listed under each preset
